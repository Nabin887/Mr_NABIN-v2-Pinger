
# Mr_NABIN v2 - Advanced Pinger

## Features
- **URL Support:** Automatically converts websites (e.g., google.com) to IP addresses.
- **Hacker UI:** Custom ASCII banner and typewriter effects.
- **Cross-Platform:** Works on Windows, Linux, and Termux.

## How to Run
1. Clone the repository:
   `git remote add origin https://github.com/Nabin887/Mr_NABIN-v2-Pinger.git`
2. Navigate to the folder:
   `cd Mr_NABIN-v2-Pinger`
3. Run the tool:
   `python nabin.py`
